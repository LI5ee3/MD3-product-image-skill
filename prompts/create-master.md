# CREATE FIVE MASTER OPTIONS

请为当前产品生成 5 个不同的 MD3 电商产品主图母版候选方案。

当前阶段不是立即确定最终母版，而是让我从 5 个方案中选择。

## 输入

产品名称：{{PRODUCT_NAME}}

版本文字：{{VERSION_TEXT}}

母版产品 PNG：{{MASTER_SKU}}

品牌：使用上传的品牌 Logo。

# 图片比例硬性限制

所有 5 个候选方案必须严格使用 3:4 图片比例。

目标尺寸固定为：

1200 × 1600 px

这是硬性限制。

不允许生成：

- 1:1
- 4:5
- 16:9
- 其他近似 3:4 的比例
- 生成后再裁切成 3:4 的替代方案

必须从生成阶段就保持严格 3:4。

# 5 个方案必须独立输出

这里的“5 个母版方案”指：

5 张完全独立的图片。

不是：

- 一张图里放 5 个方案
- 五宫格
- 拼图
- Contact Sheet
- Collage
- Grid
- Mood Board
- Comparison Board
- Storyboard
- Multi-panel Layout

每一张候选图都必须是一张完整、可单独使用和单独下载的主图。

每个候选必须独立满足：

- 严格 3:4
- 目标尺寸 1200 × 1600 px
- 一个完整 Logo
- 一个完整产品名称
- 一个完整版本文字
- 一个完整产品
- 一套完整 MD3 背景构图

图片内部不得生成：

- 01 / 02 / 03 / 04 / 05
- 方案 1 / 方案 2
- Option 1 / Option 2
- 任何用于区分候选的编号标签

候选编号只用于聊天中区分图片，不属于图片内容。

# 顺序生成规则

按以下顺序逐张生成：

方案 1 → 一张独立图片
方案 2 → 一张独立图片
方案 3 → 一张独立图片
方案 4 → 一张独立图片
方案 5 → 一张独立图片

禁止把 5 个方案合并到一张图里。

如果当前界面无法在一次回复中可靠生成 5 张独立图片：

优先保证“一张图片 = 一个方案”。

先只生成方案 1，然后停止，等待我回复“继续方案 2”。

不得因为一次无法输出 5 张独立图片，就改成拼版。


# 最高优先级：上传素材保护

上传的品牌 Logo 和产品 PNG 均为受保护源素材。

不得修改、重绘、重构、换色、重新设计或生成近似替代版本。

## Logo

不得重绘、改色、改比例、改内部结构、风格化、3D 化、金属化、添加描边/发光，或用相似 Logo 替代。

只允许等比例缩放和排版摆放。

## 产品 PNG

不得重绘产品，不得改变型号、轮廓、结构、材质、颜色、表带/机身/按键/表冠/孔位/接口等真实细节，也不得生成一个“看起来差不多”的替代产品。

只允许等比例缩放、位置调整、融入构图以及添加自然阴影和克制分离光。

构图必须围绕上传素材设计，而不是修改素材来适应构图。

# 输出要求

- 共 5 个候选方案
- 每个方案必须严格使用 3:4 图片比例
- 目标尺寸固定为 1200 × 1600 px
- 不允许生成其他比例
- 每个方案 1200 × 1600 px
- 同一个上传 Logo
- 同一个上传产品 PNG
- 完全相同的产品名称和版本文字
- 全部使用 Google Material Design 3 风格
- 适合 Ozon 等电商平台主图

五个方案必须在构图上有明显区别，禁止仅换背景色。

# 五个方案的构图差异要求

5 个方案必须是真正不同的构图方向。

禁止只是：

- 同一构图更换背景色
- 同一构图轻微移动产品
- 同一构图仅改变几何颜色
- 同一构图仅改变光影强弱

请根据当前产品自身的：

- 产品轮廓
- 产品比例
- 产品观看角度
- 产品名称长度
- 产品颜色
- 视觉重心
- 可利用留白

自由探索 5 个明显不同、但都符合 MD3 与电商主图要求的构图。

可以在以下方面自由变化：

- 产品位置
- 产品视觉尺寸
- 信息区位置
- 留白分布
- 产品与文字关系
- MD3 几何结构
- 圆弧 / 曲线位置
- Tonal Surface 使用方式
- 层次与深度
- 光影关系
- 整体视觉平衡

不要套用预设的五种固定模板。

# 允许出现

仅允许：上传 Logo、产品名称、版本文字、上传产品 PNG、MD3 背景几何、自然光影。

不得添加卖点、参数、促销标签、额外说明、额外 Logo、额外图标、徽章、装饰性英文词语、人工 UI 或平台标签。

# 文字规范

产品名称：现代无衬线，Bold 700，优先一行，最多两行，不得从单词中间断开，不得过度缩小。

版本文字：Medium 500，清晰可读，比产品名称弱一级但不能像脚注。

# 色彩

深色产品：graphite / charcoal / cool dark gray。

浅色产品：warm gray / cool gray / muted neutral。

白色产品：greige / stone / taupe / beige-gray，禁止接近纯白背景。


# Logo 原子化 QA

生成每个母版候选前后检查：

- Logo 是否作为一个完整图形保留
- 图形标与 Wordmark 是否仍然在一起
- Logo 内文字是否没有被重新排版
- Logo 内字形是否与上传素材一致
- Logo 内字距是否与上传素材一致
- 图形与文字之间的关系是否未改变
- 是否没有出现重新生成的相似品牌文字

如果 Logo 内部文字被重新生成，则该图不合格，应重新生成。

# 输出后必须停止

生成 5 个方案后停止，不要继续生成其他 SKU，等待我选择 1–5 中的一个作为正式母版。


# 最终执行顺序

先生成方案 1 的一张独立 3:4 图片。

如果系统能够继续以独立图片形式生成，则依次生成方案 2、3、4、5。

如果不能保证独立输出：

生成方案 1 后立即停止。

绝对不要将多个方案拼到同一张图中。


# 风格气质要求（活泼轻盈版 MD3）

整体必须使用 Google Material Design 3（MD3）设计语言，
但视觉气质必须偏向：

- 明亮
- 轻盈
- 活泼
- 年轻
- 清爽
- 有呼吸感
- 现代
- 电商友好
- 高级但不沉闷

不要做成：

- 太黑
- 太暗
- 太重
- 太压抑
- 太老气
- 奢侈品深色展台海报
- 黑色摄影棚布景
- 厚重的商业海报

即使当前产品是黑色或深色，也不要让整张图大面积落入纯黑或接近纯黑。

对于深色产品：

优先考虑以下 MD3 主题倾向：

- cool gray
- blue-gray
- graphite gray
- mist gray
- stone gray
- 轻微冷调中灰
- 明亮分层的中性灰

应通过更明亮的 MD3 tonal surface 分层、柔和几何和留白，
让画面保持年轻、现代和有活力。

# 底座 / 平台限制

如果使用底座、平台或展台：

- 必须偏轻
- 必须偏薄
- 必须偏柔和
- 不得过厚
- 不得成为画面的主要视觉重量中心
- 不得让画面看起来像深色展厅或老气的陈列海报

必要时可以不使用底座。

# 背景和几何要求

背景几何应体现轻盈的 MD3 层次，而不是沉重的舞台布景。

推荐：

- 柔和圆角几何
- 轻量级圆弧
- 明亮 tonal layers
- 柔和大色块
- 低压迫感留白
- 温和渐变

避免：

- 大面积纯黑背景
- 压迫感很强的深色大圆弧
- 沉重深色块
- 过多深暗区域


# 黑色 / 深色产品背景优先级规则

如果当前产品是黑色或深色：

默认优先使用更明亮、更轻盈的浅色或中浅色 MD3 背景，
而不是深色背景。

优先背景方向：

- light cool gray
- mist gray
- pale blue-gray
- soft neutral gray
- stone gray
- warm light gray
- 浅冷灰
- 浅蓝灰
- 雾灰
- 明亮中性灰

除非我明确要求深色海报风格，否则不要默认把黑色产品做成：

- 大面积黑色背景
- 接近纯黑的背景
- 很重的深色展台场景
- 深色 showroom 风格

目标是：

让黑色产品在 Ozon 等电商商品卡片中更突出、
更清爽、
更轻盈、
更容易一眼识别。

# 电商列表页优先规则

主图设计必须优先考虑电商列表页缩略图浏览场景。

优先保证：

- 产品一眼可识别
- 标题一眼可读取
- 画面整体更明亮
- 产品与背景分离清晰
- 在白色电商页面中可见性强
- 看起来更想点击

不要为了“高级感”牺牲缩略图识别度和卖货效率。
