# CREATE FIVE MASTER OPTIONS

请为当前产品生成 5 个不同的 MD3 电商产品主图母版候选方案。

当前阶段不是立即确定最终母版，而是让我从 5 个方案中选择。

## 输入

产品名称：{{PRODUCT_NAME}}

版本文字：{{VERSION_TEXT}}

母版产品 PNG：{{MASTER_SKU}}

品牌：使用上传的品牌 Logo。

# 图片比例硬性限制

所有 5 个候选方案必须严格使用 3:4 图片比例。

目标尺寸固定为：

1200 × 1600 px

这是硬性限制。

不允许生成：

- 1:1
- 4:5
- 16:9
- 其他近似 3:4 的比例
- 生成后再裁切成 3:4 的替代方案

必须从生成阶段就保持严格 3:4。

# 最高优先级：上传素材保护

上传的品牌 Logo 和产品 PNG 均为受保护源素材。

不得修改、重绘、重构、换色、重新设计或生成近似替代版本。

## Logo

不得重绘、改色、改比例、改内部结构、风格化、3D 化、金属化、添加描边/发光，或用相似 Logo 替代。

只允许等比例缩放和排版摆放。

## 产品 PNG

不得重绘产品，不得改变型号、轮廓、结构、材质、颜色、表带/机身/按键/表冠/孔位/接口等真实细节，也不得生成一个“看起来差不多”的替代产品。

只允许等比例缩放、位置调整、融入构图以及添加自然阴影和克制分离光。

构图必须围绕上传素材设计，而不是修改素材来适应构图。

# 输出要求

- 共 5 个候选方案
- 每个方案必须严格使用 3:4 图片比例
- 目标尺寸固定为 1200 × 1600 px
- 不允许生成其他比例
- 每个方案 1200 × 1600 px
- 同一个上传 Logo
- 同一个上传产品 PNG
- 完全相同的产品名称和版本文字
- 全部使用 Google Material Design 3 风格
- 适合 Ozon 等电商平台主图

五个方案必须在构图上有明显区别，禁止仅换背景色。

# 五个方案的构图差异要求

5 个方案必须是真正不同的构图方向。

禁止只是：

- 同一构图更换背景色
- 同一构图轻微移动产品
- 同一构图仅改变几何颜色
- 同一构图仅改变光影强弱

请根据当前产品自身的：

- 产品轮廓
- 产品比例
- 产品观看角度
- 产品名称长度
- 产品颜色
- 视觉重心
- 可利用留白

自由探索 5 个明显不同、但都符合 MD3 与电商主图要求的构图。

可以在以下方面自由变化：

- 产品位置
- 产品视觉尺寸
- 信息区位置
- 留白分布
- 产品与文字关系
- MD3 几何结构
- 圆弧 / 曲线位置
- Tonal Surface 使用方式
- 层次与深度
- 光影关系
- 整体视觉平衡

不要套用预设的五种固定模板。

# 允许出现

仅允许：上传 Logo、产品名称、版本文字、上传产品 PNG、MD3 背景几何、自然光影。

不得添加卖点、参数、促销标签、额外说明、额外 Logo、额外图标、徽章、装饰性英文词语、人工 UI 或平台标签。

# 文字规范

产品名称：现代无衬线，Bold 700，优先一行，最多两行，不得从单词中间断开，不得过度缩小。

版本文字：Medium 500，清晰可读，比产品名称弱一级但不能像脚注。

# 色彩

深色产品：graphite / charcoal / cool dark gray。

浅色产品：warm gray / cool gray / muted neutral。

白色产品：greige / stone / taupe / beige-gray，禁止接近纯白背景。

# 输出后必须停止

生成 5 个方案后停止，不要继续生成其他 SKU，等待我选择 1–5 中的一个作为正式母版。
