# LOCKED MASTER VARIANT REPLACEMENT

请基于已确认的母版主图生成当前颜色 SKU。

这是“锁定母版后的产品替换”，不是“重新设计一张相似海报”。

Image A = 用户选中的 ORIGINAL MASTER。
Image B = 当前颜色版本的上传产品 PNG。

# 最高优先级：素材保护

Image A 中的品牌 Logo 和 Image B 中的产品 PNG 均为受保护素材。

Logo 不得重绘、改色、改比例、改内部结构、风格化或替换成相似 Logo。

Image B 必须忠实使用。不得改变产品型号、颜色、轮廓、结构、材质、表带/机身/按键/表冠/孔位/接口等真实细节，也不得生成近似替代版本。



# Logo 原子化锁定

Image A 中的品牌 Logo 必须作为一个不可拆分的整体图形保留。

Logo 内部的：

- 图形标
- Wordmark
- 字母
- 品牌名称
- 字距
- 内部比例
- 内部对齐
- 透明关系

全部属于 Logo 本体。

不得把 Logo 内部文字识别成可编辑文本后重新排版。

不得：

- OCR 后重新打字
- 重新生成 Wordmark
- 改变字距
- 改变字形
- 改变字重
- 拆分图形标和 Wordmark
- 重建任何 Logo 内部元素

变体中必须完整保留 Image A 中原始 Logo 图形。

Logo 内的文字不是“产品名称文字”，不得重新生成。

# Logo 位置锁定

Image A 中的品牌 Logo 必须继续保持在左上角安全区。

对于 1200 × 1600 px 画布：

- 距离左边缘至少 60 px
- 距离上边缘至少 80 px
- Logo 整体必须完整位于左上区域
- 不得移动到任何其他位置

变体生成时不得为了适应新产品颜色、背景或构图而移动 Logo。

Logo 的位置、视觉尺寸和原始样式均属于锁定内容。


# Logo 大小锁定

Image A 中已经确认的品牌 Logo 尺寸属于锁定内容。

变体生成时：

- Logo 位置不得改变
- Logo 宽度不得改变
- Logo 高度不得改变
- Logo 原始宽高比不得改变
- Logo 不得因背景颜色、产品颜色或主题色变化而重新缩放

对于 1200 × 1600 px 画布，Logo 必须继续符合最大 220 × 100 px 的包围框限制。

最终变体中的 Logo 必须与 ORIGINAL MASTER 中的 Logo 保持相同视觉尺寸和位置。

# 必须锁定 Image A

严格保留：Logo 大小/位置、产品名称大小/位置、版本大小/位置、标题与版本关系、产品展示区域、产品视觉中心/尺寸、背景几何形状/大小/位置、整体构图、基本光源方向。

# 仅允许改变

- 上传替换产品 PNG
- 背景主色
- MD3 几何颜色
- 阴影强度
- 必要的轮廓分离光
- 仅为保证对比度而调整文字明暗

# 禁止

不得改变 Logo/标题/版本的尺寸和位置，不得改变背景几何结构和位置，不得改变产品展示区域和视觉尺寸逻辑，不得添加任何额外文字、卖点、参数、促销标签、图标或徽章，不得重新设计海报。

# 目标

结果应像“同一个设计母版里只替换了上传产品 PNG 和必要主题色”，而不是“GPT-image 又重新设计了一张相似海报”。


# 活泼轻盈 MD3 风格延续

在变体替换时，必须继续保持 ORIGINAL MASTER 的 MD3 设计方向，
并确保整体画面气质偏向：

- 明亮
- 轻盈
- 清爽
- 活泼
- 年轻
- 电商友好
- 高级但不沉闷

如果当前 SKU 是黑色或深色产品：

不要把背景自动处理成大面积纯黑或接近纯黑。

优先通过：

- 更明亮的中性灰 / 冷灰 / 蓝灰 tonal surface
- 更轻的几何层次
- 更柔和的留白
- 更清晰的产品边缘分离

来保持深色产品的突出，同时避免画面显得老气、压抑或厚重。

# 禁止的气质倾向

避免让变体图看起来像：

- 深色奢侈品海报
- 黑色摄影棚广告
- 厚重展台图
- 老气商业海报
- 过分稳重、沉闷的科技海报

# 底座规则

如果母版中包含底座或平台：

- 变体中不得把它变得更厚、更黑、更重
- 必须保持轻量化视觉倾向
- 若颜色适配后会导致底座过重，应通过配色和明度控制让其更轻


# 黑色 / 深色 SKU 的背景优先规则

如果当前 Image B 是黑色或深色产品：

默认优先使用更明亮、更轻盈的浅色或中浅色 MD3 背景，
不要自动沿用深黑、近黑或过重的深色背景倾向。

优先背景方向：

- light cool gray
- mist gray
- pale blue-gray
- soft neutral gray
- stone gray
- warm light gray
- 浅冷灰
- 雾灰
- 浅蓝灰
- 明亮中性灰

目标是：

让深色 SKU 在电商商品卡片中更醒目、更轻盈、更清爽，
而不是更像深色海报。
